# Olá, eu sou o Ricardo / Hi, I'm Ricardo 👋

## 🚀 Sobre mim / About me

Sou estudante de Análise e Desenvolvimento de Sistemas na ULBRA,
com conclusão prevista para o final de 2026, e estou em transição
de carreira para o desenvolvimento de software.

Após cerca de nove anos na área de logística, trago para a tecnologia
minha experiência com organização, resolução de problemas e trabalho
em equipe.

Meu foco é o desenvolvimento Full Stack com JavaScript e TypeScript,
utilizando React no front-end e Node.js no back-end. Nos meus projetos,
desenvolvo APIs REST, autenticação, integração com bancos de dados
e testes automatizados.

Busco minha primeira oportunidade profissional como desenvolvedor,
para contribuir com a equipe e continuar evoluindo na prática.
